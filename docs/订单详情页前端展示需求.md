# 订单详情页前端展示需求

基于后端OrderVo数据结构，前端订单详情页应该展示以下信息：

## 一、买家订单详情页展示内容

### 1. 固定展示信息（所有状态都显示）

#### 1.1 订单状态区
- **状态时间轴**：显示订单进度（已拍下→已提交→已接单→已交付→已收货→待评价）
- **当前状态标识**：使用OrderStatusEnum显示当前状态
- **状态说明卡片**：根据不同状态显示相应提示信息

#### 1.2 订单商品信息
基于OrderItemVo应展示：
- 商品图片 (productImage)
- 商品名称 (productName)
- 规格名称 (variantName)
- 单价 (unitPrice)
- 数量 (quantity)
- 小计 (totalPrice)
- 交付时间要求 (deliveryDay - X天内交付)
- 可修改次数 (editNum)

#### 1.3 价格信息
- 商品总价 (totalPrice)
- 运费 (freightPrice) - **前端缺失**
- 优惠券金额 (couponPrice) - **前端缺失具体显示**
- 实付款 (payPrice)

#### 1.4 订单基础信息
- 订单编号 (orderSn)
- 创建时间 (createTime)
- 付款时间 (payTime)
- 支付方式 (payType) - **前端缺失**
- 支付单号 (payTradeNo) - **前端缺失**
- 完成时间 (completeTime)
- 取消时间 (cancelTime)

#### 1.5 买卖双方信息
- 买家信息 (buyer: MemberVo) - **前端未展示**
  - 买家昵称
  - 买家头像
- 卖家信息 (tenant: MemberVo) - **前端未展示**
  - 卖家昵称
  - 卖家头像
  - 店铺名称

#### 1.6 其他信息
- 订单备注 (remark) - **前端未展示**
- 是否已评价 (evaluate) - **前端未展示**
- 收货信息 (receiverName, receiverMobile, receiverAddress) - **前端未展示**

### 2. 动态展示内容（根据状态显示）

#### 2.1 待提交材料状态 (awaitingSubmission/buyAwaitingSubmission)
- 材料要求列表 (productMaterialsVos)
- 材料提交表单
- 已提交的材料 (orderMaterials) - **前端未完整展示**
- 自动提交截止时间 (autoMaterialTime) - **前端缺失倒计时**

#### 2.2 等待开始状态 (awaitingStart)
- 卖家可接单时间 (autoOrderReceivinTime) - **前端缺失**
- 买家提交的材料列表 (orderMaterials)

#### 2.3 等待交付状态 (awaitingDelivery)
- 预计交付时间 (基于deliveryDay计算)
- 买家备注和材料

#### 2.4 待确认收货状态 (awaitingConfirmation)
- 卖家交付内容 (orderDeliveries) - **前端未展示**
- 发货时间 (deliveryTime)
- 自动确认收货倒计时 (deliveryTimestamp) - **前端缺失**

#### 2.5 售后相关状态
- 退款信息 (refundId, buyerRefundFlag, tenantRefundFlag) - **前端未展示**
- 平台介入标记 (buyerPlatformFlag, sellerPlatformFlag) - **前端未展示**

## 二、卖家订单详情页展示内容

### 1. 固定展示信息（与买家类似但有差异）

#### 1.1 订单状态区
- 同买家端

#### 1.2 订单商品信息
- 同买家端，但需要突出显示：
  - 材料要求 (productMaterialsVos)
  - 交付时间要求 (deliveryDay)
  - 可修改次数 (editNum)

#### 1.3 价格信息
- 同买家端，但需要显示：
  - 平台服务费（如果有）
  - 卖家实际收入

#### 1.4 订单基础信息
- 同买家端

#### 1.5 买家信息（重要）
- 买家昵称、头像
- 买家备注 (remark)
- 收货信息（如果是实物商品）

### 2. 动态展示内容

#### 2.1 等待开始状态 (awaitingStart)
- 买家提交的材料详情 (orderMaterials)
- 材料提交时间
- 接单截止时间

#### 2.2 等待交付状态 (awaitingDelivery)
- 买家提交的所有材料
- 交付截止时间（基于接单时间+deliveryDay）
- 买家备注

#### 2.3 待确认收货状态 (awaitingConfirmation)
- 已交付的内容列表
- 交付时间
- 等待买家确认提示

#### 2.4 已完成状态 (orderCompleted)
- 买家评价内容（如果已评价）
- 订单完成时间
- 收益信息

## 四、前端实现与后端定义的主要差异

### 1. 缺失的重要信息展示
- 买卖双方信息（头像、昵称）
- 收货信息
- 支付方式和支付单号
- 订单备注
- 材料要求详情
- 交付内容详情
- 各种倒计时（自动取消、自动确认收货等）
- 退款和平台介入标记

### 2. 状态处理不完整
- sellerSupplementaryMaterials（卖家重新交付）状态未处理
- applyForRefuse（申请拒绝）状态未处理
- applyingForMediation（平台介入）状态处理不完整

### 3. 按钮功能差异
- 部分状态下的按钮与后端API不匹配
- 缺少"查看交付"、"重新交付"等功能
- 评价功能未实现

### 4. 业务逻辑差异
- 发货接口使用错误（应该使用orderDelivery而不是ship）
- 材料提交和交付提交概念混淆
- 缺少订单需求（OrderDemand）的完整支持

## 五、建议改进

1. **完善信息展示**：按照OrderVo的完整字段展示所有相关信息
2. **补充缺失状态**：处理所有订单状态的展示和操作
3. **统一接口调用**：确保前端按钮调用正确的后端接口
4. **增加倒计时**：显示各种自动处理的倒计时
5. **完善交付流程**：区分材料提交(OrderMaterials)和内容交付(OrderDelivery)
6. **实现评价功能**：完成评价相关的展示和操作
