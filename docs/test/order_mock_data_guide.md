# 订单模拟数据使用指南

## 概述

为了方便前端开发和毕业项目测试，我们实现了一个完整的订单模拟数据系统。该系统可以在不依赖后端的情况下，展示各种订单状态和场景。

## 功能特点

1. **完整的订单状态覆盖**
   - 涵盖所有14种订单状态
   - 每种状态都有详细的测试数据

2. **无缝切换**
   - 可以在真实数据和模拟数据之间实时切换
   - 不需要重启应用

3. **买家和卖家视角**
   - 支持买家订单列表和详情
   - 支持卖家订单列表和详情

## 使用方法

### 方法一：使用模拟数据预览模式

```bash
# 运行模拟数据预览（默认启用模拟数据）
flutter run -t lib/previews/order_mock_preview.dart
```

### 方法二：在应用中手动切换

1. 进入订单列表页面（买家或卖家）
2. 点击右上角的云图标
   - 云图标（蓝色）：正在使用真实数据
   - 云图标（橙色）：正在使用模拟数据
3. 点击图标即可切换数据源

### 方法三：代码中控制

```dart
import 'package:dskk_flutter_refactor/core/config/app_config.dart';

// 启用模拟数据
AppConfig.enableMockMode();

// 禁用模拟数据
AppConfig.disableMockMode();

// 切换模拟数据状态
AppConfig.toggleMockMode();

// 检查当前状态
if (AppConfig.useMockData) {
  print('正在使用模拟数据');
}
```

1. **真实的时间戳**
   - 创建时间、支付时间等都基于当前时间计算
   - 自动超时时间设置合理

   - 计算准确的实付金额

## 测试场景

### 场景1：正常交易流程
1. 查看"待付款"订单 → 模拟支付
2. 查看"待提交"订单 → 提交材料
3. 查看"待接单"订单 → 卖家接单
4. 查看"待交付"订单 → 卖家交付
5. 查看"待确认"订单 → 买家确认
6. 查看"待评价"订单 → 完成评价

### 场景2：异常流程
1. 超时自动取消
2. 买家主动取消
3. 卖家拒绝接单
4. 申请平台介入
5. 申请售后服务

### 场景3：状态筛选
1. 点击不同的Tab查看各状态订单
2. 所有模拟订单都会正确显示在对应Tab下

## 注意事项

1. **数据持久性**
   - 模拟数据不会保存到数据库
   - 切换到真实数据后，模拟数据不会显示

2. **操作限制**
   - 模拟数据的操作（如取消、确认等）仅在内存中生效
   - 不会发送真实的API请求

3. **性能考虑**
   - 模拟数据直接从内存加载，响应速度快
   - 适合演示和UI测试

## 扩展开发

如需添加新的测试数据，可以修改：
```
lib/features/orders/data/datasources/mock_order_data_source.dart
```

添加新的订单生成方法即可。

## 常见问题

### Q: 为什么切换后数据没有变化？
A: 请确保在订单列表页面进行切换，切换后会自动刷新当前Tab的数据。

### Q: 模拟数据可以进行哪些操作？
A: 目前主要用于展示，可以查看订单详情。实际的状态转换操作建议使用专门的状态测试页面。

### Q: 如何恢复真实数据？
A: 点击云图标切换回真实数据模式，或重启应用（默认使用真实数据）。
