# Flutter路由重构 - 统一Shell架构

## 项目概述
将当前的双重嵌套路由架构（买家Shell + 卖家Shell）重构为统一的动态Shell架构，根据AppMode动态显示不同的底部导航。

### 1. UnifiedShellPage
- 根据AppMode动态显示买家/卖家底部导航

- 支持开发模式Tab

### 2. UnifiedRouteBuilder
- 根据AppMode动态创建页面内容
