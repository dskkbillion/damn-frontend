# Profile模块UI设计规范

本文档描述Profile模块的用户界面设计规范，包括各个页面布局、组件、交互方式等内容。

## 设计原则

1. **简洁明了** - 使用简洁的布局和清晰的视觉层次结构
2. **一致性** - 保持应用内部UI元素的一致性
3. **响应式** - 所有页面适配不同屏幕尺寸
4. **直观性** - 用户可以直观理解如何与界面交互
5. **可访问性** - 支持各类用户的使用需求

## 图标系统

Profile模块使用应用统一的图标库，主要包括：

- 个人资料类：用户头像、编辑、性别、日期等
- 钱包相关：钱包、交易、收入、支出等
- 操作类：返回、确认、取消、设置等

图标尺寸规范：
- 主要导航图标：24x24px
- 功能按钮图标：20x20px
- 辅助提示图标：16x16px

## 页面设计规范

### 1. 个人中心主页

个人中心主页是用户进入Profile模块的主入口，包含以下部分：

#### 顶部个人信息区

- **布局**：顶部通栏设计，高度约为屏幕高度的25%
- **背景**：使用渐变背景色（主题色到辅助色）
- **内容**：
  - 用户头像（圆形，80x80px）
  - 用户昵称（主标题样式）
  - 用户ID/用户名（辅助文本样式）
  - 编辑资料按钮（次要按钮样式）

#### 钱包摘要卡片

- **布局**：位于个人信息区下方，通栏卡片设计
- **内容**：
  - 余额信息（大字号强调）
  - 收入/支出概览（次要信息）
  - 钱包明细入口（带右箭头图标）

#### 功能区

- **布局**：网格或列表布局
- **内容**：
  - 我的订单
  - 收货地址
  - 消息中心
  - 设置中心
  - 客服中心
  - 其他功能入口

### 2. 个人资料编辑页

用于编辑用户个人资料的页面。

- **布局**：表单布局，上下滚动
- **内容**：
  - 头像编辑区（居中显示，带编辑按钮）
  - 表单项：
    - 昵称（文本输入）
    - 性别（单选框）
    - 生日（日期选择器）
    - 个人简介（多行文本输入）
  - 保存按钮（通栏主要按钮）

### 3. 钱包页面

展示用户钱包信息和交易记录的页面。

#### 钱包信息区

- **布局**：顶部卡片设计
- **内容**：
  - 账户余额（大字号）
  - 冻结金额（小字号）
  - 总收入（次要信息）

#### 交易记录列表

- **布局**：列表布局，支持下拉刷新和上拉加载更多
- **内容**：
  - 交易项目：
    - 交易图标（左侧）
    - 交易描述（主要文本）
    - 交易金额（强调文本，收入绿色，支出红色）
    - 交易时间（辅助文本）
    - 交易状态（标签样式）

## 交互设计规范

### 1. 触摸反馈

- 所有可点击元素应有明确的触摸反馈
- 按钮点击时显示水波纹效果
- 列表项点击时改变背景色

### 2. 表单交互

- 输入框获得焦点时显示边框高亮
- 表单验证错误时显示红色提示文本
- 长按输入框显示复制/粘贴菜单

### 3. 页面过渡

- 页面间导航使用右滑入场效果
- 返回上一页使用左滑出场效果
- 模态框使用渐变+缩放效果

### 4. 加载状态

- 页面加载时显示骨架屏
- 局部刷新时显示加载指示器
- 按钮操作中显示加载状态

## 响应式设计

Profile模块支持以下屏幕尺寸的响应式设计：

- **手机屏幕**（<768px）：单列布局，元素通栏排列
- **平板屏幕**（768px-1024px）：双列布局，合理利用屏幕空间
- **桌面屏幕**（>1024px）：多列布局，内容区居中，最大宽度1200px

## 可访问性设计

- 所有可交互元素需满足WCAG 2.1 AA级标准
- 提供足够的颜色对比度（正文至少4.5:1）
- 所有图片提供替代文本
- 支持屏幕阅读器
- 支持键盘导航

## UI组件复用

Profile模块复用以下通用组件：

1. **AppBar** - 顶部应用栏
2. **Avatar** - 用户头像组件
3. **Card** - 信息卡片容器
4. **Button** - 按钮组件（主要、次要、文本按钮）
5. **TextField** - 文本输入框
6. **SelectField** - 选择器
7. **DatePicker** - 日期选择器
8. **BottomSheet** - 底部弹出菜单
9. **Dialog** - 对话框
10. **Toast** - 轻提示
