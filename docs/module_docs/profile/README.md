# Profile模块

## 模块介绍

Profile模块是应用程序的个人中心功能模块，负责处理与用户个人资料相关的功能，包括资料展示、编辑、切换用户模式以及钱包信息展示等功能。该模块遵循Clean Architecture架构设计原则，确保代码的可测试性、可维护性和可扩展性。

## 核心功能

- **用户资料展示**：显示用户的基本信息，如用户名、头像、手机号等
- **资料编辑**：允许用户修改个人资料信息
- **买家/卖家模式切换**：支持用户在买家和卖家模式之间切换
- **钱包信息**：展示用户钱包的基本信息，如余额、冻结金额等
- **退出登录**：允许用户安全退出登录状态

## 技术实现

- 采用**BLoC**模式进行状态管理
- 使用**Equatable**实现对象比较
- 使用**GetIt**进行依赖注入
- 使用**dio**进行网络请求
- 使用**shared_preferences**进行本地数据缓存

## 模块结构

模块遵循Clean Architecture的分层设计：

```
lib/features/profile/
├── data/                 # 数据层
│   ├── datasources/      # 数据源
│   ├── models/           # 数据模型
│   └── repositories/     # 仓库实现
├── domain/               # 领域层
│   ├── entities/         # 业务实体
│   ├── repositories/     # 仓库接口
│   └── usecases/         # 用例
└── presentation/         # 表现层
    ├── bloc/             # 业务逻辑组件
    ├── pages/            # 页面
    └── widgets/          # 可复用组件
```

## 依赖模块

- **Authentication模块**：用于处理登录状态和退出登录操作
- **Common模块**：共享UI组件和工具类
- **Settings模块**：部分设置功能与个人中心相关
