# 订单展示优化方案

## 一、订单列表页优化方案

### 1.1 买家订单列表页

#### 布局结构
```
┌─────────────────────────────────────┐
│  Tab栏：全部 | 待付款 | 待发货 | ... │
├─────────────────────────────────────┤
│  搜索栏：搜索订单号/商品名称         │
├─────────────────────────────────────┤
│  订单卡片1                          │
│  ├─ 店铺信息栏                      │
│  ├─ 商品信息区                      │
│  ├─ 价格汇总栏                      │
│  └─ 操作按钮区                      │
├─────────────────────────────────────┤
│  订单卡片2 ...                      │
└─────────────────────────────────────┘
```

#### 订单卡片设计
```dart
OrderListCard(
  // 头部：店铺信息 + 订单状态
  header: Row[
    店铺头像,
    店铺名称,
    Spacer,
    订单状态标签(颜色编码)
  ],
  
  // 商品信息
  body: Column[
    商品图片,
    商品名称(最多2行),
    规格信息,
    "交付时间: X天" (如果有),
    数量和单价
  ],
  
  // 底部信息
  footer: Row[
    订单时间,
    Spacer,
    "共X件 合计: ¥XXX"
  ],
  
  // 操作按钮(根据状态显示1-2个主要操作)
  actions: Row[
    次要按钮(OutlinedButton),
    主要按钮(ElevatedButton)
  ]
)
```

#### 状态筛选优化
- 使用横向滚动的Chip组，支持多选
- 添加快捷筛选：近3个月、近半年
- 支持组合筛选：状态 + 时间范围

#### 新增功能
1. **批量操作**：长按进入多选模式，支持批量删除
2. **快速操作**：滑动显示快捷操作（删除、再次购买）
3. **智能排序**：默认按时间，可切换按金额、状态
4. **加载优化**：下拉刷新 + 上拉加载更多

### 1.2 卖家订单列表页

#### 特殊优化
1. **待处理提醒**：顶部显示待接单、待发货数量角标
2. **买家信息突出**：显示买家头像和昵称
3. **快速筛选**：今日订单、待处理、问题订单
4. **批量发货**：支持选择多个订单批量处理

```dart
// 根据状态显示不同的紧急信息
Widget _buildUrgentNotice(Order order) {
  switch(order.state) {
    case OrderStatus.awaitingPayment:
      return CountdownNotice(
        title: "请在${_formatTime(remainingTime)}内完成支付",
        endTime: order.autoCancelTime,
        onTimeout: () => _handleAutoCancel(),
      );
    
    case OrderStatus.awaitingSubmission:
      return CountdownNotice(
        title: "请在${_formatTime(remainingTime)}内提交所需材料",
        endTime: order.autoMaterialTime,
      );
      
    case OrderStatus.awaitingConfirmation:
      if (order.deliveryTimestamp != null) {
        return InfoNotice(
          title: "将在${_formatTime(autoConfirmTime)}后自动确认收货",
          type: NoticeType.info,
        );
      }
      
    // ... 其他状态
  }
}
```
