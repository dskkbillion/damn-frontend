# GitHub Issue #105 - 轻咨询模式付费提示功能

## ✅ 功能实现状态：已完成

### 实现摘要
成功实现了轻咨询模式下的付费提示功能，允许卖家在对话达到特定轮次（1/5/10/20条消息）时主动发送付费提示消息，引导买家选择合适的服务套餐进行付费。

### 核心功能特性

#### 1. 智能触发机制
- **基于卖家消息数量计算**：系统统计卖家发送的消息数作为对话轮次
- **里程碑触发点**：第1、5、10、20条消息后自动显示付费提示按钮
- **防重复机制**：通过记录上次发送轮次避免重复提示

#### 2. 角色身份识别
- **准确的身份判断**：通过 ChatRoom 实体的 doctorId/memberId 字段准确识别用户角色
- **动态角色检测**：避免硬编码，支持不同用户在不同聊天室的角色切换
- **持久化角色信息**：角色信息从 DTO 层传递到实体层，确保全流程准确

#### 3. 商品信息集成
- **实时加载商品详情**：自动获取关联商品的价格档位信息
- **多档位价格展示**：支持展示商品的不同服务等级和价格
- **完整的商品数据**：包含商品名称、价格、档位特性等完整信息

#### 4. 用户体验优化
- **非侵入式提示**：付费提示作为普通聊天消息，不影响对话流程
- **永久保存记录**：付费提示消息永久保存，买家可随时查看和点击付费
- **智能按钮显示**：只在达到新里程碑时显示发送按钮，避免打扰

### 已解决的关键问题

1. **角色识别错误**
   - 问题：消息中的 doctorId/memberId 在不同消息中含义不同
   - 解决：使用 ChatRoom 实体级别的固定角色ID

2. **商品信息加载失败**
   - 问题：Home 模块未初始化导致 IHomeRepository 不可用
   - 解决：调整 DI 初始化顺序，确保依赖正确注入

3. **轮次计算不准确**
   - 问题：原计算基于双方最少消息数
   - 解决：改为仅统计卖家消息数，让卖家更主动控制
