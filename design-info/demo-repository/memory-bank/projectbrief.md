# 项目简介

## 项目概述
这是一个基于React Native开发的跨平台应用项目，使用Expo框架进行开发。项目支持iOS、Android和Web平台。

## 核心功能
根据项目结构分析，主要功能模块包括：
- 用户认证系统
- AI文档处理
- 支付系统集成（包含支付宝）
- 聊天功能
- 订单管理系统
- 个人资料管理
- 服务管理

## 技术栈
- React Native
- Expo
- Tamagui UI框架
- TypeScript
- PNPM包管理器

## 项目结构
主要目录：
- `/app` - 应用程序主要路由和页面
- `/components` - 可复用组件
- `/constants` - 常量定义
- `/sdk` - 核心功能SDK
- `/assets` - 静态资源
- `/ios` & `/android` - 原生平台代码

## 当前分支
- 当前位于 `simulator_arm64` 分支
- 主要用于ARM64架构模拟器的适配工作

## 项目目标
1. 跨平台兼容性
2. 高性能用户界面
3. 安全可靠的支付系统
4. 流畅的AI文档处理体验
5. 完善的订单管理功能

## 开发规范
1. 使用TypeScript确保代码类型安全
2. 组件化开发，提高代码复用性
3. 遵循React Native最佳实践
4. 使用PNPM进行依赖管理
