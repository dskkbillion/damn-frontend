# DSKK前端设计风格指南（更新版）

## 概述

本文档旨在梳理和规范DSKK前端项目的设计风格，确保所有页面和组件在视觉上保持一致性，提供良好的用户体验。设计追求现代感、清晰性和易用性，同时保持品牌特色。

## 配色方案（更新版）

### 主题色（单色调设计）

- **主色调**: `#FF7D1A`（现代橙色）
- **浅色变体**: `#FFE0CC`（10%饱和度）
- **中浅色变体**: `#FFBD80`（30%饱和度）
- **中深色变体**: `#E66500`（80%饱和度）
- **深色变体**: `#CC5A00`（100%饱和度）

主题色采用单色调设计，使用不同明度和饱和度的变体，主要用于强调重要的交互元素和关键信息，避免过度使用导致视觉疲劳。

### 中性色（优化版）

- **主要文本**: `#212121`（更深的灰色，增强可读性）
- **次要文本**: `#757575`
- **第三级文本**: `#9E9E9E`
- **提示文本**: `#BDBDBD`
- **浅色背景**: `#FFFFFF`（纯白色背景）
- **浅灰背景**: `#F5F5F5`
- **中等背景**: `#EEEEEE`
- **深色背景**: `#E0E0E0`

中性色是页面的主要构成部分，用于文本、背景和边框等元素。

### 边框色

- **浅色边框**: `#EEEEEE`
- **中等边框**: `#E0E0E0`
- **深色边框**: `#BDBDBD`
- **分割线**: `#F5F5F5`

### 功能色（优化版）

- **成功**: `#66BB6A`（更柔和的绿色）
- **警告**: `#FFD54F`（更柔和的黄色）
- **错误**: `#EF5350`（更柔和的红色）
- **信息**: `#42A5F5`（更柔和的蓝色）

功能色用于表示不同状态和提示信息。

## 排版

### 字体

使用系统默认字体栈，确保在不同设备上的最佳显示效果：
```css
font-family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif;
```

### 字体大小

- **大标题**: 20px，字重700
- **标题**: 18px，字重600
- **副标题**: 16px，字重500
- **正文**: 14px，字重400
- **小文本**: 12px，字重400

### 行高

- **默认行高**: 1.6
- **紧凑行高**: 1.3
- **宽松行高**: 1.8

## 组件样式

### 按钮

按钮有四种主要类型：

1. **主要按钮**（Primary）
   - 背景色: 主题色 `#FF7D1A`
   - 文本色: 白色
   - 用于页面主要操作
   - 可选：使用渐变背景 `linear-gradient(135deg, #FF7D1A, #E66500)`

2. **次要按钮**（Secondary）
   - 背景色: 白色
   - 边框: 1px solid `#E0E0E0`
   - 文本色: 次要文本色 `#757575`
   - 用于次要操作

3. **第三级按钮**（Tertiary）
   - 背景色: 透明
   - 文本色: 主题色 `#FF7D1A`
   - 用于辅助操作
   - 悬停时显示浅色背景

4. **轮廓按钮**（Outline）
   - 背景色: 透明
   - 边框色: 主题色 `#FF7D1A`
   - 文本色: 主题色 `#FF7D1A`
   - 用于特殊场景，如可取消的操作

按钮圆角为8px，内边距为12px 24px。

### 卡片

卡片是内容的容器，具有以下特点：

- 背景色: 白色
- 圆角: 12px
- 阴影: `0 1px 2px rgba(0, 0, 0, 0.05)`
- 内边距: 20px
- 外边距: 0 0 20px 0

### 表单元素

#### 输入框

- 边框: 1px solid `#E0E0E0`
- 圆角: 6px
- 内边距: 14px
- 聚焦时边框色: 主题色 `#FF7D1A`

#### 标签

- 背景色: 中等背景色 `#F5F5F5`
- 文本色: 次要文本色 `#757575`
- 圆角: 4px
- 内边距: 4px 8px
- 外边距: 0 8px 8px 0

### 列表

列表项具有以下特点：

- 内边距: 16px
- 边框底色: 分割线 `#F5F5F5`
- 最后一项无底边框

### 导航栏

#### 顶部导航栏

- 背景色: 白色
- 高度: 56px
- 阴影: `0 1px 2px rgba(0, 0, 0, 0.05)`
- 文本色: 主要文本色 `#212121`
- 标题字体大小: 18px，字重600

#### 底部导航栏

- 背景色: 白色
- 高度: 56px
- 阴影: `0 -1px 2px rgba(0, 0, 0, 0.05)`
- 非活动项文本色: 次要文本色 `#757575`
- 活动项文本色: 主题色 `#FF7D1A`
- 图标大小: 20px
- 文本大小: 12px

### 进度条

进度条用于显示订单等流程的进度：

- 背景线条: 中等背景色 `#EEEEEE`
- 活动线条: 主题色 `#FF7D1A`
- 完成步骤: 主题色背景 `#FF7D1A`，白色图标
- 活动步骤: 主题色背景 `#FF7D1A`，白色图标
- 未完成步骤: 白色背景，灰色边框 `#E0E0E0`

### 状态提示

状态提示用于显示不同类型的提示信息：

- **信息提示**
  - 背景色: 主题色的10%透明度 `rgba(255, 125, 26, 0.1)`
  - 文本色: 主题色 `#FF7D1A`

- **警告提示**
  - 背景色: 警告色的10%透明度 `rgba(255, 213, 79, 0.1)`
  - 文本色: 警告色 `#FFD54F`

- **成功提示**
  - 背景色: 成功色的10%透明度 `rgba(102, 187, 106, 0.1)`
  - 文本色: 成功色 `#66BB6A`

- **错误提示**
  - 背景色: 错误色的10%透明度 `rgba(239, 83, 80, 0.1)`
  - 文本色: 错误色 `#EF5350`

### 标签页

标签页用于在同一区域切换不同内容：

- 非活动标签: 次要文本色 `#757575`
- 活动标签: 主题色 `#FF7D1A`，底部有2px主题色指示线
- 内边距: 14px 0
- 边框底色: 分割线 `#F5F5F5`

## 间距系统

使用一致的间距系统确保页面元素之间的关系清晰：

- **4px**: 极小间距，用于相关元素内部
- **8px**: 小间距，用于紧密相关的元素之间
- **12px**: 中小间距，用于组件内部元素
- **16px-20px**: 中间距，用于组件之间
- **24px**: 大间距，用于主要内容区块之间
- **32px**: 极大间距，用于页面主要部分之间

## 响应式设计

- 移动容器最大宽度: 414px
- 小屏幕适配（320px以下）:
  - 内容内边距: 12px（默认16px）
  - 卡片内边距: 12px（默认20px）
  - 按钮内边距: 10px 20px（默认12px 24px）

## 设计原则

1. **简洁性**: 保持界面简洁，避免视觉杂乱
2. **一致性**: 在整个应用中保持一致的视觉语言
3. **层次感**: 通过颜色、大小、间距创造清晰的视觉层次
4. **可用性**: 确保界面易于理解和使用，增强交互欲望
5. **反馈**: 为用户操作提供清晰的视觉反馈

## 设计风格要点

1. 使用单色调设计，主题色（现代橙色）主要用于强调重要的交互元素和关键信息
2. 大量使用白色和不同深浅的灰色作为背景和边框，创造清爽简约的视觉效果
3. 使用更大的圆角和更轻微的阴影，增加现代感
4. 增加战略性留白，创造清晰的视觉层次和呼吸感
5. 使用一致的字体大小和更宽松的行高，提高可读性
6. 交互元素（如按钮、链接）有明确的视觉提示，增强交互欲望

## 实现注意事项

1. 使用CSS变量管理颜色和其他设计值，便于统一修改
2. 组件样式应该是可复用的，避免重复代码
3. 确保所有交互元素有足够大的点击区域（至少48x48px）
4. 考虑不同设备和屏幕尺寸的适配
5. 确保足够的颜色对比度，提高可访问性
6. 在关键交互元素上使用单色调设计，增强视觉一致性
7. 使用柔和的功能色，减少视觉干扰
