# DSKK前端极简设计风格指南

## 设计理念

极简主义（Minimalism）是我们设计的核心理念，强调"少即是多"（Less is More）。通过减少不必要的元素，突出内容本身，创造清晰、高效、优雅的用户体验。

## 核心原则

1. **减法设计**：移除一切非必要元素，只保留最核心的功能和内容
2. **留白为王**：充分利用留白创造呼吸感和视觉焦点
3. **内容优先**：设计应该服务于内容，而不是喧宾夺主
4. **一致性**：保持视觉语言的一致，减少用户的认知负担
5. **功能性**：每个设计元素都应该有明确的功能目的

## 配色方案

### 主色与辅助色

- **主色调**: `#b66d0e`（橙色）- 仅用于关键操作按钮和重要信息
- **黑色**: `#212121` - 用于主要文本
- **白色**: `#FFFFFF` - 用于背景
- **灰色**: `#F5F5F5`、`#EEEEEE`、`#E0E0E0` - 用于分隔和次要背景

### 色彩使用原则

1. **极度克制**：整个界面以黑白灰为主，主题色仅点缀使用
2. **比例控制**：主题色占比不超过10%
3. **目的明确**：色彩必须有明确的功能目的，不为装饰而使用
4. **对比适中**：避免过强的色彩对比，追求和谐统一

## 排版

### 字体

- 使用单一无衬线字体，推荐系统默认字体栈
- 字重限制在Regular(400)和Medium(500)两种，特殊情况下使用Bold(700)

### 字号体系

- **大标题**: 20px (700)
- **标题**: 18px (500)
- **副标题**: 16px (500)
- **正文**: 15px (400)
- **辅助文本**: 13px (400)
- **微小文本**: 12px (400)

### 行高

- 正文行高：1.5
- 标题行高：1.3

## 间距系统

采用8px为基础的间距系统：

- **4px**: 极小间距（内部元素）
- **8px**: 小间距（紧密相关元素）
- **16px**: 中间距（组件内部）
- **24px**: 大间距（组件之间）
- **32px**: 特大间距（主要内容区块）

## 组件设计

### 卡片

- **无阴影**：使用极细的边框（1px）代替阴影
- **大圆角**：12px统一圆角
- **少嵌套**：避免卡片中再嵌套卡片
- **宽松内边距**：上下左右均为20px

### 按钮

- **扁平化**：无渐变、无阴影
- **简单形状**：矩形+圆角（8px）
- **状态明确**：禁用状态透明度降低至40%
- **尺寸适中**：高度统一为44px，宽度根据内容自适应

### 表单

- **标签内置**：将标签放在输入框内部，获焦时上浮
- **边框简化**：仅使用底部边框
- **反馈即时**：输入时实时验证和反馈
- **对齐一致**：所有表单元素左对齐

### 列表

- **无边框**：列表项之间使用细分割线
- **留白充足**：列表项内边距为16px
- **层次分明**：主要信息和次要信息字号、颜色区分明显

## 图像使用

### 图片风格

- **高质量**：使用专业、高清晰度图片
- **风格统一**：所有图片色调、风格保持一致
- **简洁构图**：避免复杂、杂乱的图片

### 图标系统

- **线性图标**：统一使用1.5px线条的线性图标
- **尺寸统一**：导航图标24px，功能图标20px，指示图标16px
- **对齐网格**：所有图标严格对齐到8px网格

## 交互设计

### 反馈原则

- **即时反馈**：用户操作后立即给予视觉反馈
- **微妙过渡**：使用150-200ms的简单过渡效果
- **状态明确**：不同状态间有明确的视觉差异

### 手势支持

- **触控友好**：所有可点击元素至少48x48px
- **滑动流畅**：支持自然的滑动和滚动
- **直观操作**：避免复杂的手势操作

## 实现要点

1. **CSS精简**：避免过度使用CSS属性，追求精简代码
2. **语义化HTML**：使用正确的HTML元素表达内容结构
3. **响应式设计**：确保在不同设备上都能保持简约美观
4. **加载性能**：优化资源加载，确保界面快速呈现
5. **可访问性**：确保足够的颜色对比度和键盘可访问性

## 设计检查清单

在完成设计后，请检查以下几点：

- [ ] 是否移除了所有非必要元素？
- [ ] 留白是否充足且有意义？
- [ ] 色彩使用是否克制且有目的？
- [ ] 排版是否清晰且层次分明？
- [ ] 交互是否直观且提供及时反馈？
- [ ] 视觉语言是否在整个界面保持一致？
- [ ] 是否考虑了不同设备和屏幕尺寸？
