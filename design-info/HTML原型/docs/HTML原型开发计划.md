## 注意事项

1. 所有页面都应遵循统一的设计原则：
   - 使用主题色#b66d0e，配合橙色和不同深浅的灰色和黑色
   - 采用iOS自适应布局，适合手机应用
   - 限制分辨率，最大宽度为414px
   - 设计追求现代感、清晰性和易用性

2. 所有页面都应实现完整的跳转逻辑，确保用户可以在不同页面之间自然导航。

3. 页面开发应参考新原型截图，确保UI设计与新版本一致。
