# DSKK前端页面功能与跳转逻辑

本文档详细描述了DSKK前端各个页面的主要功能和页面间的跳转逻辑，为开发团队提供清晰的导航参考。

## 主要导航结构

DSKK应用采用底部标签栏导航结构，包含四个主要标签页：

1. **首页**（index.html）
2. **AI对话**（ai_docs.html）
3. **消息**（chat.html）
4. **我的**（profile.html）

用户可以通过底部标签栏在这四个主要页面之间自由切换。

## 页面功能与跳转逻辑

### 第一批：主标签页

#### 1. 首页 (index.html)
- **主要功能**：展示推荐服务、热门故事和活动信息
- **跳转逻辑**：
  - 点击服务卡片 → 服务详情页(service_detail.html)
  - 点击故事卡片 → 故事详情页(story.html)
  - 点击搜索框 → 搜索页面(search.html)
  - 点击消息图标 → 通知页面(notification.html)

#### 2. AI对话页面 (ai_docs.html)
- **主要功能**：提供AI辅助服务，包括问答、推荐等功能
- **跳转逻辑**：
  - 点击历史记录 → AI对话历史记录页面(ai_docs_history.html)
  - 点击输入框 → AI对话输入页面(ai_docs_input.html)
  - 点击问题卡片 → AI对话问答页面(ai_docs_question.html)
  - 点击推荐卡片 → AI对话推荐页面(ai_docs_recommendation.html)

#### 3. 消息页面 (chat.html)
- **主要功能**：展示用户的聊天列表
- **跳转逻辑**：
  - 点击聊天项 → 聊天详情页面(chat_detail.html)
  - 点击搜索图标 → 搜索页面(search.html)

#### 4. 个人资料页面 (profile.html)
- **主要功能**：展示用户个人信息和功能入口
- **跳转逻辑**：
  - 点击头像/昵称 → 编辑个人资料
  - 点击我的订单 → 订单页面(orders.html)
  - 点击我的收藏 → 收藏页面(favorites.html)
  - 点击我的钱包 → 钱包页面(wallet.html)
  - 点击账号安全 → 账号安全页面(account_safe.html)
  - 点击成为卖家 → 卖家认证页面(seller_auth.html)
  - 点击卖家中心 → 卖家个人资料页面(seller_profile.html)
