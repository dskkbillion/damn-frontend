支付协议
引言

本支付协议（"协议"）是由DSKK（"我们"、"我们的"或"本应用"）与您（"用户"）之间就支付服务达成的协议。在使用我们的支付服务前，请仔细阅读本协议的全部内容。

通过使用我们的支付服务，您确认您已阅读、理解并同意受本协议的约束。如果您不同意本协议的任何条款，请勿使用我们的支付服务。

支付方式

我们接受以下支付方式：

  • 银行卡支付：支持国内主要银行发行的借记卡和信用卡。
  • 支付宝：通过支付宝账户进行支付。
  • 微信支付：通过微信账户进行支付。
  • 平台余额：使用您在平台上的余额进行支付。

我们保留随时更改支持的支付方式的权利，恕不另行通知。

费用与收费

使用我们的支付服务可能会产生以下费用：

  • 服务费：根据您购买的服务类型，我们可能会收取一定比例的服务费。具体费率将在您下单前显示。
  • 提现费用：从平台提现到银行卡可能会产生手续费，具体费率将在提现页面显示。
  • 货币兑换费用：如涉及货币兑换，可能会产生相应的兑换费用。

所有费用均以人民币计价，除非另有说明。

订单与支付流程

当您在我们的平台上下单时，您需要遵循以下流程：

  1. 选择您想购买的服务
  2. 确认订单详情和价格
  3. 选择支付方式
  4. 完成支付
  5. 接收订单确认通知

一旦您完成支付，订单将被处理，您将收到订单确认通知。

退款政策

我们的退款政策如下：

  • 服务未开始：如果服务尚未开始，您可以申请全额退款。
  • 服务已部分完成：如果服务已部分完成，退款金额将根据已完成的部分按比例扣除。
  • 服务已完成：一旦服务完成，除非存在质量问题，否则不予退款。
  • 特殊情况：某些特定服务可能有特殊的退款政策，将在服务详情页面说明。

退款将在申请批准后的7-15个工作日内退回到您的原支付账户。

安全保障

我们采取多种安全措施保护您的支付信息：

  • 所有支付信息均通过SSL加密传输
  • 我们不会存储您的完整银行卡信息
  • 我们使用多重身份验证保护您的账户
  • 我们定期进行安全审计和系统更新

尽管如此，互联网交易存在固有风险，我们建议您也采取措施保护自己的账户安全。

争议解决

如果您对支付或退款有任何争议，请按以下步骤处理：

  1. 首先通过我们的客服渠道提交争议
  2. 提供相关订单号和问题描述
  3. 我们将在5个工作日内回复您
  4. 如果问题无法解决，您可以向相关监管机构投诉
协议修改

我们保留随时修改本协议的权利。修改后的协议将在我们的网站或应用上发布，并在发布时立即生效。继续使用我们的支付服务即表示您接受修改后的协议。
